# GuitarPal 练习录音与成果对比规划

更新日期：2026-10-15

## 目标

练习录音服务于两个不同但关联的场景：

1. **片段练习录音**：用户针对当前整曲或 A-B 片段录制自己的演奏，立即在“原曲”和“我的录音”之间切换回听，先依靠听感判断节奏、音准、动态和连贯性差异。
2. **计划成果录音**：用户把一次满意的录音保存为某个练习计划的阶段成果，按日期形成时间线，并选择不同日期的录音连续回听，感受长期进步。

首版只做可靠的录制、保存、回听和人工对比。自动音频分析作为后续阶段，不影响录音主链路交付。

## 当前进度

- [x] R1 Android 录音基础：麦克风权限、AAC/M4A 原生录制、安全临时文件提交、应用私有文件管理、数据库 v8、仓库与 Android 集成测试。
- [x] R2 片段录音与人工对比：本地视频/B站播放器录制、同位置切换回听、保存，以及详情页多次试录管理均已接入。
- [x] R3 计划成果时间线：明确保存入口、计划成果时间线、双录音同位置切换与顺序回听均已接入。
- [ ] R4 自动音频分析探索：用户录音的本地波形、响度、静音占比和实验性起音间隔分析已接入；原曲节奏对齐与音高分析继续开发。

## 产品约定

- 默认录制的是用户演奏声，而不是把原曲与用户演奏混成一个文件。
- 录音时允许原曲或 A-B 片段继续播放，界面提示优先使用有线或蓝牙耳机，避免扬声器串音影响回听和后续分析。
- 每次录音保留当时的来源、片段区间、播放倍速、计划和练习时间等快照；之后编辑片段或计划不会篡改历史录音含义。
- 普通试录可以关联来源或片段；只有用户明确点击“保存为计划成果”后，才进入计划成果时间线。
- 音频文件保存在应用私有目录，数据库只保存元数据与相对路径。删除录音时同步删除音频文件。
- 麦克风权限只在用户首次点击录音时申请；拒绝后仍可正常使用播放器和其他练习功能。

## 数据模型

新增独立的 `PracticeRecording`，避免把多次试录硬塞进单条 `PracticeSession`：

| 字段 | 用途 |
| --- | --- |
| `id` | 录音稳定标识 |
| `sourceId` | 对应练习来源 |
| `segmentId` | 可选，对应 A-B 片段 |
| `planId` | 可选，保存为计划成果时使用 |
| `sessionId` | 可选，关联产生录音的练习记录 |
| `kind` | `segmentTake` 或 `planOutcome` |
| `filePath` | 应用私有目录中的音频相对路径 |
| `duration` | 录音时长 |
| `referenceStart` / `referenceEnd` | 录制时的原曲区间快照 |
| `referenceSpeed` | 录制时的原曲倍速快照 |
| `title` / `note` | 用户标题与主观复盘 |
| `recordedAt` | 录制时间，用于成果时间线 |

未来的自动分析使用单独的 `RecordingAnalysis`，通过 `recordingId` 关联，并记录算法版本、分析状态和指标；这样升级算法时可以重新计算，不改动原录音。

## 页面与导航

### 练习播放器

- 在本地视频和 B站练习播放器的非全屏控制区增加“录音”入口。
- 点击后先处理权限，再显示 3 秒倒计时；录制状态持续显示时长和停止按钮。
- 开始录音时记录当前播放位置、A-B 区间和倍速；有活动片段时默认按片段语义保存。
- 停止后进入录音预览：播放“原曲片段”或“我的录音”，填写标题/复盘，并选择保存为普通试录、保存为当前计划成果或丢弃。
- 原曲和用户录音使用以片段起点为 0 的相对时间轴；切换播放对象时尽量保持同一相对位置，便于反复听同一个音符或节奏点。
- 录音流程首版在普通练习页完成；倒计时、录制或预览未结束时暂不允许进入应用全屏，避免录音状态和未保存文件丢失。

### 练习详情与片段

- 来源详情增加“练习录音”区域，按片段分组并按时间倒序展示。
- 片段卡片展示录音数量，并可进入该片段的录音列表。
- 录音支持播放、暂停、重命名、补充复盘、保存为计划成果和删除。

### 计划成果

- 计划卡片增加“成果录音”入口。
- 成果页按时间线展示日期、片段、录音时长、倍速和复盘。
- 用户可选择两个不同日期的成果进入并排对比：两侧同步展示日期、录音信息和相对进度，使用共享时间轴定位同一位置。
- 对比时一次只播放一条录音；在较早/较新录音之间切换时保持相同相对位置，也可按“较早录音 → 较新录音”连续回听。首版不把两条音频同时混放，也不自动宣称进步或退步。
- 优先比较同一来源、同一片段及相近区间的成果；历史快照不一致时显示提示，避免误导用户。
- 无成果时提示用户从该计划进入练习，并在录音预览中保存为成果。

## 分阶段开发

### R1：Android 录音基础（完成）

- 麦克风权限与拒绝/永久拒绝状态处理。
- Android 原生录音桥接，首选 AAC-LC/M4A，并写入应用私有目录。
- 开始、停止、取消、异常中断和文件清理。
- `PracticeRecording` 领域模型、数据库表、仓库与迁移测试。

### R2：片段录音与人工对比（完成）

- [x] 播放器录音入口、麦克风权限、3 秒倒计时、录音计时、停止/取消和预览状态。
- [x] 记录来源、计划、已保存片段、A-B 区间与 0.01 精度倍速快照。
- [x] 原曲与用户录音使用共享相对时间轴，可在同一位置切换、播放、暂停和拖动。
- [x] 详情页按时间倒序展示多次试录，支持独立播放、进度拖动、重命名、复盘和删除。
- [x] Android 模拟器真实验证录制、M4A 提交、加载回听、跳转、暂停、路径解析及删除。

### R3：计划成果时间线（完成）

- [x] 从计划进入练习时，将录音关联到该计划。
- [x] 录音预览可直接保存为计划成果，已关联计划的普通试录也可显式转为成果。
- [x] 成果时间线、两个日期录音的顺序对比和空状态引导。
- [x] 两条成果并排展示、共享相对进度和同位置切换回听；区间快照不一致时给出提醒。
- [x] 成果元数据与音频沿用本地私有存储，并支持同步删除。

### R4：自动音频分析探索

- [x] Android 本地解码用户 M4A 录音，展示波形、平均/峰值响度、静音占比和起音数量；在起音样本充分时展示间隔中位数与波动，不生成演奏评分。
- [ ] 节奏：对本地视频参考区间提取起音，完成节拍对齐、抢拍/拖拍和稳定性比较。
- [ ] 音高：单音旋律可先做音高轨迹；和弦、失真吉他及复音场景需要多音高或 chroma 方法，准确性要单独验证。
- [ ] 动态与连贯性：在参考音轨可用时比较响度包络、停顿和音符持续时间差异。
- 分析结果必须显示置信度与适用范围，不能把低可信结果包装成确定结论。
- 本地视频较容易获得可分析的参考音轨；B站 WebView 首版不能假定可以提取原始音频，因此先支持人工回听，自动分析需另行验证参考音频的合法、稳定获取方式。

当前算法、限制和后续验证顺序见 [音频分析探索](audio_analysis_exploration.md)。

## 首版验收标准

- 用户可从本地视频或 B站练习页开始、停止或取消录音。
- 权限拒绝、来电/切后台、播放器退出或录音异常不会留下无法管理的损坏记录。
- 保存后的录音可独立回听，并能切换回对应原曲区间人工比较。
- 同一片段允许保存多次试录，用户可以重命名、写复盘和删除。
- 从计划进入练习产生的录音可以明确保存为计划成果。
- 计划成果按日期展示，并支持选择较早和较新的两条录音并排展示、在同一相对位置切换或顺序回听。
- App 重启后录音元数据和音频文件仍可用；删除操作同时清理文件。

## 暂不进入首版

- 自动给出演奏总分或“进步百分比”。
- 云端上传、公开分享或跨设备同步录音。
- 从第三方网页播放器抽取、下载或永久保存原曲音频。
- 多轨编辑、降噪、伴奏分离和专业 DAW 功能。
