# 本地视频练习页布局

更新：2026-10-31。

页面按「视频 → 常驻播放控制 → 当前和弦 → 页内工具」组织。视频高度随可用空间调整，不再用固定最小高度挤掉控制区；标题保持一行，长标题省略。当前和弦的小图和指法设置继续沿用，完整波形／和弦时间轴位于音频区。

## 常用操作

- 进度、当前／总时间、播放／暂停、前后 5 秒固定在视频下方。滚动分轨、录音或片段列表不会把它们卷走。
- 点击左侧倍速值打开完整调速弹层，保留数字输入、滑动、0.01 步进和预设；点击右侧音量图标打开音量／静音弹层。两者使用原控制器，不创建新播放器。
- 小屏或键盘弹出时收起次要和弦展示；可用高度极低且正在输入时暂让播放条给编辑区域让位，键盘关闭后恢复。输入、滚动位置和播放器状态均保留。

## 页内工具

| 分区 | 内容 |
| --- | --- |
| 循环 | A／B 设点、保留毫秒精度的时间、循环开关／完成次数、清除、保存为片段 |
| 音频 | 和弦／分轨分析、波形与和弦时间轴、已有任务、下载恢复、选轨、混音台 |
| 录音 | 倒计时、录制、回听、命名与保存 |
| 片段 | 已保存片段列表、应用、编辑、删除及保存当前区间 |

进入默认显示循环。顶部分析菜单和当前和弦校准直接切到音频分区；全屏返回保持先前分区。录音倒计时、录制、草稿试听／保存期间锁定录音分区，完成或取消后恢复切换。

四个内容视图保持挂载，共用原视频控制器与练习 recorder。分区切换不停止录音、不重建分析任务、不重置倍速／A-B，也不重复计算练习时长。各分区使用独立的 ScrollController，在当前页面保留滚动位置；不把滚动偏移写入与内部 ExpansionTile 共用的 PageStorage 标识，避免把数值偏移当成折叠布尔状态读取。

本次优化范围为本地视频练习页；AI 能力仍沿用现有 Debug 开放策略和私网配置，未变更数据库或 Windows 服务。
