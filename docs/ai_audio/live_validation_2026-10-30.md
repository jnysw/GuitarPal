# 2026-10-30：真机连接与分析边界修复

本次复核使用用户已部署的 Windows API、Mac 与 Android 模拟器。源地址从被忽略的部署 JSON 读取；本文不公开用户域名、私网 IP、任务 ID 或媒体内容。

## 连接与构建

- 用户确认报错发生在实体安卓手机，且手机未安装 Tailscale。当前测试服务通过 Tailscale Serve HTTPS／443 对同一 tailnet 提供服务；Windows 内部仅监听 `127.0.0.1:8000`，客户端不应直连该回环端口。
- Windows 在 tailnet 中在线且 ping 可达。实际 HTTPS 健康接口返回 200 与 `{"ping":"pong"}`；Tailscale IP:8000 连接超时。Mac 代理影响了初次 curl，诊断用 `--noproxy '*'` 直连成功；模拟器未配置全局代理。
- 没有传 `API_BASE_URL` Dart 参数的 Android 构建，能通过原生配置读取开发 JSON 并成功请求同一个 HTTPS 健康接口。普通启动和成品 APK 不依赖用户手填地址。
- 手机仍需安装并连接同一 Tailscale 网络。本次无实体手机 USB 连接，未声称手机安装／网络闭环已验收；公网部署仍不在本批范围。

## 输入与结果边界

- 自生成 8 秒 H.264／AAC 视频放入隔离测试使用的应用私有视频目录，由 MediaExtractor／MediaCodec 提取 PCM16；用户媒体没有上传。
- 复现容器时长 8000ms、播放器传入时钟 8001ms 时，旧检查会报超出视频。修复后原样输出 8001ms 和相应 PCM 帧数。请求真正超过播放器末尾仍失败，传入过期的 7000ms 时钟也会被新 MediaPlayer 复核拒绝。
- 真实和弦结果声明时长 7.850s，末段结束 7.895s，差 45ms，旧 20ms 检查拒绝。v1 现在仅容忍 50ms 内的尾部差异，保留声明与原分段，界面说明轻微尾差；不容忍重叠、乱序、更大越界或整个区间位于声明时长之后。新严格协议未放宽，静音裁剪偏移仍未知，仍需人工校准。
- A-B 被清除后不会悄悄退回整段上传，用户可关闭「仅分析 A-B」回到整段模式。

## 真实任务

- Android 提取的同一份自生成 8 秒音频通过 HTTPS 提交，和弦识别任务完成并返回 C major／C；这是链路样本，不是准确率基准。首次拒绝及修复时查询使用生成样本，未提交用户音频。
- 分轨使用服务默认设备和 `wav_s16`，单次约 63 秒完成，结果包含七轨，时长与 8 秒输入相符。该耗时只是此次任务记录，不代表通用性能、设备配置或质量验收。
- 记录任务回执后，后续回归通过构建参数复用已有 job ID，仅 GET 状态和结果，不重复推理。此处未重复验证全部音轨听感；完整下载／混音覆盖见前批测试。
