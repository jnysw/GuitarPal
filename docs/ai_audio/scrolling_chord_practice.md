# 随播放滚动的和弦跟练带

更新：2026-10-31。入口仍为本地视频练习页，在当前和弦下方显示，足够空间时随工具分区一起常驻；全屏提供紧凑跟练带。小屏／键盘时沿用练习工作区的空间优先规则。

- 和弦横向排列，宽度按其真实持续时间分配。视窗显示约 8 秒原媒体内容，播放位置约位于左侧三分之一，给后续和弦留出预读空间。播放线不依赖计时器猜测，而由原视频媒体时钟驱动；UI 使用主题强调色。
- 同一和弦持续期间也推进，普通播放用短线性滚动衔接更新；暂停定位、较大 seek 和 A-B 回跳直接对齐，不慢慢划过已跳过的部分。倍速不改变原曲坐标或每秒比例，校准偏移只加一次。
- 当前和弦高亮，后续可提前看到。间隙不延续上一和弦；N 和 X 保留各自语义，区间外不高亮。点击可见和弦仍需校验当前文件绑定，跳转到原视频位置。
- 手动横向浏览暂停自动跟随，显示「回到当前」；点击后恢复。其他任务刷新返回内容相同的结果时，不强制抢回用户正在浏览的位置。校准或换分析结果则重新对齐。
- 二分查找可视窗口并只布局可见和弦单元，不为整段结果同时创建所有控件。跟随滚动不会拖动视频进度，也不影响录音、A-B、混音与练习会话。系统减弱动画时直接对齐。

本轮没有更改算法结果、静音裁剪策略或自动校准能力。结果未人工校准时，仍明确提示“按分析区间起点显示 · 静音偏移待校准”。

组件 `ScrollingChordLane` 接收 `VideoChordPlayback`、当前原媒体毫秒位置及播放状态，可以供未来演奏空间复用；演奏空间当前仅完成 [规划](../performance_space/development_plan.md)，未新增舞台页面。
