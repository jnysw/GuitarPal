# 本地视频内的和弦与分轨

更新：2026-10-28。依据用户对 AudioJam 的参考，AI 能力围绕已经导入的练习视频展开，不新增一级模块，也不要求再导入一份音频或手动关联曲目。

## 当前操作路径

1. 从「新建 → 相册／文件」导入本地视频，或从练习库／计划打开已有视频练习。
2. 点击播放器右上角「和弦与分轨」图标，选择「扒和弦」或「分离音轨」；也可直接展开播放器内同名面板。
3. 分析整段视频或当前 A-B，支持 2 秒至 10 分钟。确认曲目、区间和接收服务后，只提取并上传音频，视频留在本机。提取结果必须小于等于 50 MiB；较长的高采样率视频需缩短 A-B。
4. 任务、波形和结果直接显示在当前播放器内，自动绑定来源及当前计划。停止查询不取消服务器任务；重新打开视频后继续查询，已缓存 JSON 和下载的音轨可离线复用。
5. 和弦先显示分析相对时间。当前 Windows 接口会裁剪静音但不返回偏移，用户需输入「分析 0 秒对应的视频时间」完成一次人工校准，之后显示当前／下一和弦，点击和弦定位同一视频。人工偏移单独保存，机器结果保持原样，不能将此称为自动精确同步。
6. 分轨完成后点击「在当前视频中使用分轨」，下载六条模型音轨。共用原播放器的播放、进度、音量、0.01 倍速及 A-B；各轨音量／静音／独奏在可折叠面板中调整。进入覆盖区间时自动静音视频原声，区间外恢复原声。「切回视频原声」释放分轨并保留位置、暂停播放。

同一来源的近期结果按任务类型显示，前台展开面板时才轮询。进入全屏保留分析面板状态，退出后继续调整。录音流程开始时会先切回视频原声，避免「原曲」比较使用了用户的混音设置。

目前仅 Debug Android 本地视频开放；B站 WebView 不提供可提取音频，不向其伪造分析能力。旧 `/audio-tools` 及独立分轨页保留内部测试／历史兼容，但已移除「我的」中的入口，不再作为产品主流程。

## 数据与播放关系

```text
PracticeSource + 现有视频播放器
  ├─ 当前位置 / 倍速 / A-B / 录音 / 唯一练习会话
  └─ VideoAnalysisPanel（页内）
       ├─ VideoAudioExtraction → 区间 PCM16 WAV + 波形 + 输入 SHA-256
       ├─ AlgorithmTaskRecord → 现有 Windows 上传、查询、结果及下载服务
       └─ VideoAnalysisBinding → 来源 + 文件信息 + 提取区间 + 人工和弦偏移
            ├─ 和弦定位 → 原 LocalVideoPlaybackController
            └─ 分轨 → 同一 LocalVideoPlatformView 内 StemMixEngine
```

- Drift v12 → v13 增加可空 `mediaBindingJson`，旧任务、统计归属与结果保留。旧「关联曲目」仅表示统计归属，没有媒体绑定的任务不会用于视频定位。
- 映射保存来源 ID、私有路径、文件大小、修改时间、原视频时长、提取区间及完整输入 WAV 的 SHA-256。重新应用结果时校验来源／路径／大小／修改时间；这属于文件元信息校验，尚非整段原视频的内容哈希修订系统。
- Android 使用 MediaExtractor／MediaCodec 解码，按输出时间戳裁切、补间隙及尾部静音，不移除静音或对区间加速。提取只接受已导入的应用私有视频。
- 混音限定相同格式的 PCM16 WAV，六轨共享 AudioTrack 音频时钟；视频画面跟随音频媒体位置。音频位置转换为视频坐标只加一次提取起点，不乘除倍速。派生伴奏不与六轨重复叠加。
- 视频位置每 100ms 更新；画面偏差超过 120ms 时纠正，纠正间隔至少 500ms。这是首版同步策略，尚非逐样本音画锁定；沿用视频既有 180ms 容差 A-B，不能将毫秒输入精度当作循环准确度。
- 复用原视频练习 recorder，不增加第二条分轨练习会话。任务缓存不进入 Supabase 元数据 outbox；无鉴权 Windows 服务仍只用于私测。

## 验证与下一步

`video_analysis_binding_test.dart` 覆盖文件变化拒用、显式人工校准与 v12 迁移；`video_analysis_panel_test.dart` 使用契约替身覆盖提取请求、上传确认、自动来源归属及和弦定位。

Android `video_analysis_playback_test.dart` 使用自生成 8 秒 MP4，实际提取 1–3 秒 PCM、校验 WAV／波形／哈希，并验证同一视频中的分轨原声静音、1.37 倍速、跳转、区间外恢复、A-B 及释放。`local_video_analysis_workspace_test.dart` 验证播放器菜单至分析、校准、定位、退出只保存一条会话。此处算法响应为测试数据，不代表模型准确率，也未对用户视频重新发起推理。

本批最终静态分析无问题，完整 Flutter 测试 313 项通过，上述 Android 集成 2 项及原视频画面／错误恢复／全屏回归 3 项通过。全屏往返仍使用同一控制器，人工校准结果保留。真机、长视频及实际推理结果的同步听感尚未验收。

下一批围绕同一播放器迭代：和弦与波形的横向时间轴／缩放／A-B 标记、选择和弦区间保存练习片段、音轨设置与选中结果的自动恢复、真实视频长时间音画同步及耳机音质验收。服务端补回静音偏移后再开放自动和弦同步；指法库、节拍网格与模型质量仍按原规划分别验收。当前没有完整复刻参考图的桌面布局。
