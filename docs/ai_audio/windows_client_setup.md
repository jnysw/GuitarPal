# Windows 算法客户端联调

更新：2026-10-30。当前开发入口为 Tailscale Serve HTTPS／443，和弦与分轨共用一个源地址，按路径分流。Windows 的 `127.0.0.1:8000` 是内部监听，不是手机连接地址。该服务仅供同一 tailnet 开发测试。

## 配置和入口

开发者将已部署的 HTTPS 源地址写入本机 `config/algorithm.local.json`（已忽略，不进入 GitHub），格式见 `config/algorithm.example.json`。Android Gradle 会自动编译到原生配置中，因此普通 IDE 启动／`flutter run`／APK 构建也能读取，普通用户不填写地址。与既有账号配置一起启动：

```bash
flutter run --dart-define-from-file=config/supabase.local.json
```

开发者仍可用 `--dart-define=API_BASE_URL=https://YOUR_TAILNET_HOST` 覆盖；兼容旧 `ALGORITHM_BASE_URL`。没有 Dart 配置时读取 Android 构建配置，Gradle 的 `API_BASE_URL` 环境变量优先于本机 JSON。修改部署配置后需要重新构建 APK，热重载不会修改原生构建值。地址只包含 HTTPS 源，不加 `/api/v1` 或内嵌密码。构建缺失配置时提示服务暂不可用；页面没有地址表单。已有任务保留创建时的源地址，不迁移 job ID 到其他服务。

Debug Android 构建：从新建／练习库／计划打开本地视频，在播放器右上角选择「扒和弦」或「分离音轨」。Mac 的 Tailscale 需保持连接，Windows 需开机并运行算法服务。模拟器通过 Mac 网络访问，独立 Android 真机也需要可访问该 tailnet。TLS 使用正常校验，不绕过证书。

实体安卓手机需先从 [Tailscale 官方 Android 下载页](https://tailscale.com/download/android) 安装，登录与 Mac／Windows 相同的 tailnet 并开启连接。2026-10-30 用户确认实体手机尚未安装，这是手机不可达的已知原因。APK 内置地址不等于自动获得私网权限；尚未部署面向普通用户的公网 API。

提交前先以 8 秒上限做只读健康检查，成功后再提取／上传。连接失败时不提取、不创建任务，提供「重试连接」；私网连接错误提示检查 Tailscale。健康检查只证明服务可达，模型是否成功仍以具体任务结果为准。POST 回执丢失仍保留接收未知，不自动重传。

Release 仍隐藏无内置账号鉴权的实验服务入口。旧联调页的「检查连接」只调用 `/api/v1/health/ping`，不能证明模型已就绪。

### 明文 HTTP 私网测试

Debug 接受局域网／回环／Tailscale `100.64.0.0/10` 范围的数值 IP，例如 `http://100.64.0.10:8000`（示例，请换成实际 IP／端口）。Windows 必须开机、Tailscale 在线，算法服务监听可访问的网卡地址，并放行该端口；只监听 `127.0.0.1` 的服务无法直接通过 Tailscale IP 访问，仍可使用既有 Serve HTTPS 入口。不要把 HTTPS 域名直接改成 `http://` 并假定 80 端口已配置。

明文 HTTP 仅保留开发者构建／契约测试能力，不在练习页提供地址切换。当前 Windows 服务仅监听回环 8000，客户端采用已验证的 HTTPS／443；直接使用 Tailscale IP 加 8000 在本轮实测超时。BASE_URL 不加 `/api/v1`；健康检查使用 `/api/v1/health/ping`，文档使用 `/api/docs`。

2026-10-29 用户未开机时所有连接均不可达。2026-10-30 已确认 Windows 在线，HTTPS 200，模拟器真实 GET／上传／结果验证成功；Mac 带本机代理的 curl 曾超时，指定 `--noproxy '*'` 后直连成功。仅诊断命令绕过代理，不修改系统代理设置。用户私网地址仅留本机配置，不提交到公开仓库。

## 操作流程

以当前本地视频为中心，无需另选音频文件：选择整段／当前 A-B → 确认上传音频 → 页内任务与结果。来源和计划自动继承，使用原播放器的唯一会话。分析区间为 2–600 秒，提取后的 PCM16 WAV 不超过 50 MiB；较长的高采样率视频请缩短区间。

和弦结果按本次区间起点暂显当前／下一和弦，静音偏移待校准时会标记；点击「与视频时间校准」设置算法 0 秒对应的视频时间。当前服务静音偏移缺失，人工校准仅调整显示，不修改原始结果。分轨结果点击「在当前视频中使用分轨」，按实际算法清单下载模型轨（不叠加派生伴奏），使用原视频控制器播放、拖动、倍速与 A-B；原声静音防止叠加，区间外恢复原声。各轨音量／静音／独奏／声像在页内调整，切回原声会保留位置并暂停。

下载支持两条并行、自动 GET 重试及条件断点续传，暂停或重启后点击原结果继续，不用再次分析。相同来源／区间已有结果时优先提示复用。新任务使用 FLAC16 减少传输，Android 在本机解码后混音，旧 WAV 继续兼容；详见 [传输与缓存恢复](stem_transfer_recovery.md)。计算耗时、下载字节／速度与本机解码分别显示，不能把服务器处理时间算成网络速度。

重新打开视频可看到已保存的任务、校准及结果；完整下载的分轨可离线再次载入。文件变化时拒绝把旧结果用于定位。录音开始时回到视频原声。详见 [视频练习工作区](video_practice_workspace.md)，其中列出了同步精度、输入限制及下一步 UI 迭代。

## 旧联调工具（历史兼容，已移除个人中心入口）

以下独立音频／录音流程保留内部验证，产品主路径使用上面的本地视频页内工具。

1. 选择音频文件或已有练习录音，选择“和弦分析”或“分离音轨”。系统文件导入会创建私有副本；支持 MP3/WAV/FLAC/OGG/M4A，2–600 秒且不超过 50 MiB。
2. 确认接收服务器、文件和上传用途后提交。multipart 字段为 `audio`，参数放 query。客户端不发送 Supabase token，也不根据显卡型号擅自选择设备，沿用服务端默认配置。
3. 收到 202 后保存任务 ID 和类型，前台每 2 秒查询。处理阶段进度与上传字节进度分开；服务端未提供处理百分比时显示不定进度。
4. 离开任务页/打开结果页/进入后台会停止后续轮询；回到任务页恢复查询。停止查询不等于远端取消。响应丢失的 POST 不自动重传；重启或过期引起的 404/410 明确提示任务失效。
5. 和弦 JSON 可离线查看。旧接口时间基于裁剪静音后的音频，尚不用于原曲定位、同步或 A-B；默认 1.0 不作为模型置信度展示，不显示兜底 BPM。
6. 分轨结果列出人声、鼓、贝斯、吉他、钢琴、其他、伴奏七轨。伴奏保留 `derived` 含义。清单落盘不代表音频已下载；到期前需逐条“下载到本机”。显示服务端 `expires_at` 的本地时间。
7. 下载以流式写入 `.part`，检查长度、类型和 WAV/FLAC 采样格式，再原子改名到持久私有目录 `algorithm_stems`，保存本地校验收据。失败/中断不显示为已下载；服务器支持可靠条件续传时重试从断点获取。服务器已到期时仍能试听本机完整文件。
8. 点击“试听”播放单条音轨；或“进入分轨练习”，对已下载的 PCM16 WAV 使用共享进度、0.50–2.00x（0.01 步进）、A-B 循环、主音量和各轨音量/静音/独奏。六轨混音或人声＋伴奏两种模式互斥，切换后保持位置并暂停；“保存练习设置”供下次恢复。离页停止，进入后台暂停；关联曲目／整曲计划后计入既有统计，未关联仍为试听；视频同步与片段计划仍待开发。详见 [分轨练习说明](stem_mix_practice.md)。
9. “移除本机记录”清理本机 JSON、导入副本和已下载音轨，不删除用户原有练习录音，也不取消远端任务。正在下载时不能删除该任务。离开结果页后已开始的下载可继续，应用进程被系统终止时下次需重试。

## 验证与后续

实测记录见 [2026-10-28 联调](live_validation_2026-10-28.md)。协议/页面测试仍使用明确标记的合成 fixture，不能据此声明模型准确率。

视频区间提取、元信息绑定、人工校准定位和原播放器分轨已有首版；自动静音偏移、整段媒体内容哈希、连续可缩放和弦时间轴、指法库、真机音质／音画延迟、跨账户权限及生产持久任务系统继续按规划开发。Windows 上游内存任务服务不具备生产队列的重启恢复保证。本批视频工作区测试使用合成 MP4 和算法契约替身，未重新请求用户视频推理；此前真实 API 验证与本批界面／原生验证分别记录。

复现真实接口冒烟（仅上传脚本生成的节奏音频）：

```bash
python3 tools/smoke_legacy_algorithm.py --base-url https://YOUR_TAILNET_HOST
```

输出与下载默认位于 `/tmp/guitarpal-live-smoke`，不提交到 Git。独立 Android 原生试听测试：

```bash
flutter test integration_test/algorithm_stem_playback_test.dart -d emulator-5554
```

若提供 `--dart-define-from-file=config/algorithm.local.json --dart-define=SMOKE_SEPARATION_JOB=<未过期的已完成任务ID>`，还会执行 Flutter HTTPS 下载真实吉他音轨并本机试听的测试；不提供时仅跳过该联网项。
