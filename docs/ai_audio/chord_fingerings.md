# 视频练习中的离线指法

更新：2026-10-31。入口为本地视频旁的「指法设置」（手形按钮），继续使用原播放器，没有新增一级页面。

## 使用

- 「显示指法图」默认关闭。打开后在视频旁显示当前和弦的小图，宽屏兼顾下一和弦；全屏用更小的当前图，保留现有进度与返回顺序。完整指法和切换操作在底部弹层，避免挤占练习控制区。
- 弹层随播放、定位和 A-B 回跳切换当前和弦；没有和弦或未知时不显示手型。操作指法不发起服务器请求，不修改音频、识别标签、校准、倍速或 A-B。
- 左右箭头切换实际收录的指法并记为该和弦的常用指法，星标可恢复推荐。设置为全局本机偏好，后续来源沿用；以标准定弦下的规范和弦键记忆，过期或找不到的 ID 回退推荐。
- 左手显示仅镜像图形，数据始终从六弦低 E 到一弦高 e。图上提供弦号、空弦圈、不弹叉、指号、横按与高把位标记；读屏逐弦描述实际品位及指号。
- 指法是标准定弦的推荐参考，不声称还原视频手型。不自动移调、设置变调夹或按倍速改音高；没有精确匹配时明确显示“暂未收录”，本批未开放简化参考。

## 数据与边界

固定 [chords-db 提交](https://github.com/tombatossals/chords-db/tree/df06fa7b425cf5fd29485ff6591236b3557e3fac)，MIT 作者和完整许可打包，可在弹层离线查看。转换命令、输入 SHA-256 与紧凑资源 schema 见 [署名与重现说明](../../third_party/chords-db/README.md)。App 运行不下载第三方指法库。

已转换 1,693 个指法、433 个规范和弦键。覆盖 12 个根音 × 14 类非斜杠质量的 168 个组合；433 包含这些组合与实际可用的斜杠低音键，不表示覆盖任意转位或所有复杂和弦。剩余 57 个候选位置因完整和弦音／低音／指号／横按校验未通过被排除，不能把本批排除数解释为整个上游库的错误率。完整清单见 [覆盖报告](chord_library_coverage.json)。

`GuitarChord` 单独解析根音、quality 和 bass，支持等音与常见模型别名；Harte 斜杠级数按根音换算，不能把 `/3` 当绝对低音。显示保留原拼写，查询用 pitch class；如 C/E 没有正确最低音的指法不能作为精确结果。未知质量不自动降为大三和弦。

资源从相对正品位换为绝对品位，空弦保持 0，与标准定弦算出的 MIDI 逐弦核对；要求全部规范和弦音存在且没有未声明的额外音。推荐按较少横按、较小跨度、较低把位、较少按弦排序，不声称是客观难度评级。指法图使用 App 原生绘图，已替换旧 18 个固定手型数据源。

`chord_display_v1.json` 保存开关、左右手和常用指法，串行原子写入；失败保留当次显示并提示重试。没有数据库迁移或元数据同步。本批不包含用户导入、非标准定弦、完整扩展和弦、Capo、移调或原演奏手型推断。
