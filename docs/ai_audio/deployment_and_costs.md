# Windows 联调、云端迁移与成本估算

记录日期：2026-10-27。用户确认：两个模型已在另一台 Windows 主机成功返回结果。硬件为 **RTX 5070 Ti 16GB、AMD 9600X、DDR5 32GB**，云端私测月预算 **低于人民币 100 元**。计划先使用该主机 API 测试，正式发布再迁到租用服务器。成功返回结果是用户报告，尚未由当前开发环境复现或测量性能。尚未授权购买或创建付费资源。

## 当前建议

按当前预算，**Windows 主机承担全部测试推理，暂不长期租用云 GPU**。先完成真实纵向闭环，再按实际剩余预算决定是否短租 GPU 验证 Linux 部署。原估算的 10–20 小时只是价格对照，不作为当前购买计划。显存容量已知，模型权重、推理参数、音频时长及实测 RTF 仍缺，当前不能据此确定上线 GPU 型号或承诺每次任务成本。

先从局域网手机联调开始，API/开发数据库/队列/临时音频都可放本地，继续使用当前 Supabase 登录项目的既有额度。新增云 GPU 租金为零；电费、组网服务及超额费用仍需按实际情况计入。测试调度初始限制为一次仅执行一个 GPU 重任务，队列串行处理，基准通过后再调整并发。

App 始终调用 GuitarPal 自有 `/v1` 接口。公开 API 管理 Supabase 身份、任务和结果；模型适配器在其后调用 Windows 引擎或云端引擎。测试和生产环境分别配置 API 地址，任务/结果语义保持一致，不在客户端集成上游各自协议或写死 Windows IP。

| 阶段 | API / 持久任务 | 模型执行 | 验收目的 |
| --- | --- | --- | --- |
| 个人联调 | 本地/Windows 的 GuitarPal API | 用户现有 Windows 环境 | 验证真实输入、权重、时间轴与 App 流程 |
| 小范围私测 | 可放常驻 CPU 主机，PostgreSQL 保存状态 | Windows 私有引擎；后续短期租 GPU 对照 | 断线/关机后任务能重排，API 与模型不绑在同一台机器 |
| 上线 | HTTPS API、持久任务与私有存储 | Linux GPU worker 或按需 GPU 适配器 | 按实际用量决定常驻与按需，完成安全/恢复/成本验收 |

现有 Windows 推理环境可先保留。规划中的 Celery worker/Redis 等基础设施优先在 Linux/WSL2 或 Linux 容器中运行；[Celery 官方不支持原生 Windows](https://docs.celeryq.dev/en/stable/faq.html#does-celery-support-windows)。若仍由原生 Windows 引擎推理，Linux worker 可通过私有 HTTP 适配调用，不要求立即迁移已跑通的模型环境。

低频按需 GPU 与常驻 Celery worker 是两种调度形态：若以后选 Runpod Serverless，dispatcher 应调用其执行接口并将提供商任务映射到自有 job/step；不能把需要常驻拉取队列的 Celery worker 原样当成短生命周期 handler。

## 联调网络

- 同一局域网先连接 Windows 测试地址，验证手机到主机的可达性。
- 跨网络个人测试可使用私有组网；例如 [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve) 仅向同一 tailnet 的授权设备提供本地服务，并支持 HTTPS。需要参与设备加入组网；这不等于向所有 App 用户提供公共 API。
- 对外私测使用带鉴权的 HTTPS 入口，继续验证 Supabase JWT 和每个资源的所有者。上游模型接口只供适配器访问。
- 主机关机/休眠/断网必须显式显示不可用或等待恢复，不能让 App 永久“分析中”。服务端持久任务/租约/重试仍属 M1 待实现项。

## 查询到的参考价格

2026-10-27 查询 [Runpod 官方价格页](https://www.runpod.io/pricing)（页面标记 2026-10-08 更新）：所显示 RTX 4090 Pod 为 **$0.89/GPU 小时**，4090 Serverless Flex 为 **$1.10/worker 小时**。地区、库存及计费产品会影响实际可选报价，下单前重新核对；这里只用于量级估算，不表示已选定供应商或该模型必须使用 4090。

| 使用方式 | 估算 GPU 费用（美元） | 假设 |
| --- | --- | --- |
| 现有 Windows 联调 | 新增云 GPU 租金 $0 | 电费、现有机器折旧和网络另计 |
| 云 GPU 部署验证 | $8.90–$17.80 | 4090 Pod 启动累计 10–20 小时，用后停止 GPU |
| 一张 4090 Pod 持续开机 30 天 | $640.80 | $0.89 × 720 小时，与是否有用户提交任务无关 |
| 按需分轨，10 次/日，每次 3 分钟 | 纯推理 $8.25/月 | RTF=0.5，30 天、$1.10/小时，不含启动/闲置 |
| 按需分轨，100 次/日，每次 3 分钟 | 纯推理 $82.50/月 | 同上 |

按需两行的 **RTF=0.5 是计算假设，尚未实测**。RTF=1 时纯推理费用翻倍，RTF=0.25 时减半；其他 GPU 的速度与价格需要同时比较。

计算公式：

```text
每月有效推理小时 = 每日任务数 × 每次音频分钟 × RTF × 30 / 60
每月 GPU 账单 = 实际计费 worker 小时 × 小时单价
总账单 = GPU + CPU/API/队列 + 数据库/身份 + 存储 + 流量 + 其他固定费用
```

Serverless 不能只用推理小时当账单：[官方计费说明](https://docs.runpod.io/serverless/pricing) 还包含 worker 启动/模型加载及缩容前 idle timeout，已缩容的 worker 不计 GPU 费。可先为纯推理费预留 1.5–2 倍预算，再用基准替换这个预留系数；这不是性能承诺。实际磁盘、存储和传输费用仍另算。

当前 [Supabase 官方价格](https://supabase.com/pricing) 提供 Free（$0/月，含 1GB 文件存储、5GB 出站等限制）与 Pro（从 $25/月起，具体计算/超额另计）。现有登录项目可继续测试，音频长期留存/下载不能默认为免费；Supabase 本身也不提供这两个 PyTorch 模型所需的 GPU 推理。

若用户主要在中国大陆，应另测部署地区到用户和现有 Supabase 项目的上传、下载与登录可达性，再比较国内供应商的实时报价。不能只比较 GPU 单价就确定上线区域。本轮不估算未核实的国内供应商价格或实时汇率。
