# 分轨练习（实验）

当前产品入口是本地视频练习页；本文以下保留 2026-10-28 独立联调页的首版说明。2026-10-30 新增两条并行下载、条件续传、缓存校验及 FLAC16 本机解码，旧 PCM16 WAV 继续兼容，见 [传输与缓存恢复](stem_transfer_recovery.md)。

更新：2026-10-28。本批在既有下载/单轨试听基础上增加离线多轨练习，不调用新的模型，也不改写原本地视频或 B站播放器。

## 页面与使用

入口：我的 → 音频工具（实验）→ 已完成分轨 → 下载音轨 → 进入分轨练习。

- “分轨混音”使用人声、鼓、贝斯、吉他、钢琴、其他六条中已下载的文件；“人声＋伴奏”使用这两条中已下载的文件。未下载的轨道会标为未载入，不参与独奏判定。
- 点击播放/暂停，统一进度条拖动所有音轨。切换模式会暂停并保持媒体位置；需要用户再点播放。
- 各轨音量、静音和独奏；可多选独奏，静音优先，点亮独奏会先取消该轨静音。主音量影响全部输出；全静音时仍保持时间线。
- 复用 0.50–2.00x / 0.01 精度倍速控件，支持滑动、按键微调、精确数字输入和常用值。Android 变速参数固定 pitch=1；设备拒绝参数时显示错误并恢复界面上次生效设置。
- A-B 可用当前位置设点，或直接输入秒数（最多三位小数）。区间至少 250ms，必须位于音轨内；启用循环后 seek 限于 A-B 内。页面显示循环计数。
- “保存练习设置”保存模式、音量/静音/独奏、倍速及启用中的 A-B，下次载入恢复；不会自动播放。当前位置本身不跨重启恢复。
- 后台和音频焦点丢失会暂停，返回前台不自动播放；退出页面释放输出。通过“关联曲目／计划”选择统计归属后，实际播放会进入既有练习历史及整曲计划进度；未关联时仍为试听，详见 [统计说明](stem_practice_statistics.md)。

## 播放实现

`AlgorithmMixPlugin` / `StemMixEngine` 使用一个 `AudioTrack` 和硬件播放头，按共同帧位置读取所有轨，再输出一个 PCM16 流。位置由已播放的帧数换算，不按 UI Timer 推算；A-B 在送入输出流时拼接对应帧，不通过 Flutter 定时 seek。暂停保留队列，seek/循环区间变动先 pause/flush 重建同一时间映射。时间伸缩器在文件尾部可能需要额外输入，增加无声排空数据但不计入源时长。

AudioTrack 的播放头以帧计数，需按无符号 32 位解读，flush 会重置；高速播放需要足够的缓冲。实现按官方 [AudioTrack 参考](https://developer.android.com/reference/android/media/AudioTrack) 处理计数回绕和最小缓冲，`PlaybackParams` 固定音高参数。

每批最多读取 512 帧/轨，内存与曲目时长无关，不一次性解码整曲。各轨以固定增益线性求和，再作用主音量并限幅；静音/独奏不会按当前轨数重新归一化而放大其他轨。这不是专业母带响度处理器，输出过载时可能限幅失真，应调低主音量或各轨增益。静音/音量变动在既有输出缓冲消耗后生效，未承诺零延迟或零接缝噪声。

`StemPcmWave` 解析 RIFF 的 fmt/data 与未知/奇数填充块，验证 PCM16、1/2 声道、8–96kHz、块对齐、时长和文件边界。同一组文件必须采样率、声道一致，帧数差不超过 1。仅访问 `algorithm_stems` 私有目录，拒绝任意外部路径；伴奏与乐器六轨叠加也在原生层拒绝。

服务默认 `wav_s16` 可直接使用。FLAC、浮点 WAV、不同采样率/声道/长度组合不在本批混音支持范围；已有单轨试听和下载流程保留。

## 设置与数据

`StemMixSettings` 明确模式、各轨控制、主音量、倍速和循环，JSON `version=1`；读取时校验字段和值域，坏设置回退默认并提示。保存为 `algorithm_stems/<local-task-id>_mix.json`，先写 `.part` 再改名。只保存设置，不保存新的音频副本、网络地址或账号 token。已有任务删除会按任务前缀清理设置。数据库保持 v11，旧练习/录音/计划记录不变。

## 验证与限制

本批 Android 集成覆盖共享时钟、1.37 倍速、暂停/seek、原生 A-B 多轮、慢速文件尾部停止、带未知填充块的 WAV、不同格式/采样率拒绝、伴奏重复和越目录拒绝；另复用既有 Windows 任务测试真实六轨混音和人声＋伴奏模式，原始音频仍是上批的合成测试样本，不代表模型音质基准。

Flutter 页面覆盖精确倍速输入、非法/合法 A-B、静音/独奏、模式切换和保存；领域/文件测试覆盖未下载独奏不影响现有轨、非法设置、原子保存与删除。

本批完整 Flutter 测试 304 项通过，静态分析无问题。Android 两个集成文件共 5 项通过；其中三项多轨/格式测试，两项既有试听回归。联网项复用上批未过期的服务端任务，不重新运行模型。联调使用上批同一组 44.1kHz / 双声道 / 8秒真实模型输出，测试结束清理自己的下载副本。

复现本地原生测试（联网项默认跳过）：

```bash
flutter test integration_test/algorithm_mix_test.dart integration_test/algorithm_stem_playback_test.dart -d emulator-5554
```

追加 `--dart-define-from-file=config/algorithm.local.json --dart-define=SMOKE_SEPARATION_JOB=<已有未过期任务ID>` 可运行实际七轨下载/六轨与双轨播放项。真实任务必须包含完整 8秒测试音频，以匹配测试的 1–1.8 秒循环与末尾边界。
