# 分析准备取消与恢复

2026-11-23，基于当前 `codex/ios-ai-port` 工作区。

## 操作

在本地视频练习中确认和弦分析或分轨后，连接检查及提取阶段显示「取消本次分析」。点击后进入「正在结束音频准备…」，原生提取返回后清理本次临时文件并恢复提交按钮。用户可以继续播放和练习。

切到后台、开始录音或更换播放器会使本次准备结果失效。回到前台后，过时结果仍需清理。开始上传后，状态由既有任务系统管理，按服务器回执继续查询。

## 实现边界

当前取消在客户端阻止后续提交，原生提取仍会完成当前操作，收尾期间保留忙碌状态。这样可以清理准确的临时路径，并避免同时启动多个提取操作。原生流式提取的协作取消和进度事件后续再接。

本轮增加准备版本号和阶段标记，复用已有提取器、任务服务及临时文件清理。取消期间的迟到错误会随原操作收尾。已进入任务系统的回执和提交状态继续保留。

## 验证

Flutter 全量 492 项通过，静态分析通过。定向回归覆盖手动取消、提取期间后台后立即恢复、临时音频清理、任务表保持为空和随后重新提交。已有播放、同区间复用和人工校准流程通过。

本轮 iPhone 18 Pro／iOS 27.2 模拟器完成非零 A-B 音频提取及和弦工作区、FLAC 选轨下载和离线重开两项集成回归。用例使用真实本地媒体提取与解码、替身算法和下载响应。线上会话预检用例保持默认跳过，公网 `/health` 只读返回 `status=ok`、`guest_access=true`，没有新增公网推理任务。实体设备的音质、耳机切换和资源压力继续按开发计划验收。
