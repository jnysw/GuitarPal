# GuitarPal 页面与导航规划

更新日期：2026-10-26

这份规划把“功能模块-2”中的功能重新组织为用户旅程。思维导图描述的是能力边界，页面结构不按每个分支机械拆页。

## 一级导航

| 入口 | 目的 | 当前状态 |
| --- | --- | --- |
| 今日 | 今日任务、练习入口、最近内容和进度摘要 | 已接入当天计划、自动/补记练习记录、完成比例和练习摘要 |
| 练习库 | 曲目/来源搜索、筛选、片段与笔记管理 | 来源与笔记搜索、平台/完成/计划状态组合筛选、手动完成标记、公开页面标题/封面、来源信息与链接复制、曲目总体笔记、片段局部笔记、Markdown 导出、详情、重命名和删除已接入 |
| 新建 | 从分享链接、本地相册或文件创建内容 | 分享链接与 Android 本地视频均已打通 |
| 计划 | 新建/维护计划、今日与周进度、提醒 | 新建、编辑、删除、今日/本周进度、提醒中心与计划卡快捷提醒、播放器自动/检查点记录和“补记本次”已接入 |
| 我的 | 训练反馈、本地身份、账号、设置、支持与反馈 | 练习反馈已拆为可折叠二级页；本地模式、账号同步规划、主题模式和默认练习倍速设置已接入；支持和问题反馈继续按真实状态标注 |

“新建”是全局动作，不是第五个内容 Tab。关闭新建流程后，用户应回到发起操作前的一级页面。

## 页面层级

```text
应用
├── 今日 /today
├── 练习库 /library
│   └── 内容详情 /library/source/:sourceId
├── 计划 /plans
│   ├── 新建计划 /plans/new
│   ├── 编辑计划 /plans/:planId/edit
│   ├── 提醒中心 /plans/reminders
│   ├── 单计划提醒 /plans/:planId/reminder
│   └── 成果录音 /plans/:planId/recordings
├── 我的 /profile
│   ├── 练习反馈 /profile/insights
│   ├── 账号与同步 /profile/account
│   └── 应用设置 /profile/settings
├── 音频工具（实验，仅 Debug） /audio-tools
├── 新建练习 /create
│   ├── 链接解析与确认 /inbox
│   └── 本地视频确认 /create/local/:draftId
└── 全屏练习
    ├── 从详情进入 /library/source/:sourceId/practice?segmentId=...
    ├── 直接恢复 /practice/:sourceId?segmentId=...
    └── 从计划进入 /practice/:sourceId?planId=...&segmentId=...
```

录音预览作为练习播放器内的阶段界面，不新增一级导航；来源/片段录音从内容详情进入，计划成果录音从对应计划进入。

“我的 → 音频工具（实验）”为 Windows 算法服务联调入口，可选择音频/已有录音、确认上传、恢复任务并查看离线结果；旧版和弦时间轴尚不用于原播放器定位或 A-B。分轨服务未完成时显示未开放。后续真实时间协议与媒体修订完成后，再按来源详情/播放器流程合并入口。

## 核心用户路径

### 创建并开始练习

1. 在任意一级页面点击“新建”。
2. 粘贴平台链接或完整分享文案。
3. 检查解析结果、修改练习名称。
4. 选择“稍后练习”进入内容详情，或选择“现在开始”进入全屏播放器。
5. 在播放器设置倍速与 A-B 区间，并把有效区间保存为片段。
6. 需要时调整媒体音量；全屏播放时点击画面唤起进度、音量和播放控制。

本地视频使用同一条主流程：在“新建”选择相册或文件，确认名称后保存到练习库或直接开始。原文件不会被修改，GuitarPal 管理自己的私有副本。

### 从练习库复用

1. 在练习库搜索并打开内容详情。
2. 从详情页开始完整练习，或点击已有片段直接进入对应 A-B 区间。
3. 在详情或播放器中编辑片段名称、A/B 时间、默认倍速和练习笔记；打开片段时自动恢复区间与倍速。
4. 从详情页的曲目笔记卡片导出 Markdown；系统分享不可用时仍可复制曲目及片段笔记全文。
5. 不支持 App 内播放的平台统一显示“引用模式”，保留打开原内容的明确出口。

### 按计划练习与记录

1. 在“今日”或“计划”打开当天计划；本地视频和 B站来源显示“开始练习”，引用型来源显示“打开原内容”。
2. 从计划进入 App 内播放器时，路由携带 `planId`，播放器以计划中的整曲/片段目标为准，避免把记录写到错误来源或片段。
3. 本地视频或 B站练习会记录实际播放时长和 A-B 循环次数，并刷新今日完成进度；暂停和应用后台时间不计入。进入后台时先写入恢复检查点，正常退出时再用最终记录覆盖同一条数据。
4. 引用型来源在外部应用中练习，或播放器自动记录有遗漏时，使用“补记本次”填写分钟数或循环次数。
5. 计划页的“本周进度”按周一至周日显示每日状态，并汇总本周完成项、有效时长、记录数和循环数。
6. 调整提醒时可点击计划卡上的提醒状态，或从计划页右上角/个人中心进入提醒中心，无需打开完整编辑器。

### 查看反馈与账号状态

1. “我的”只展示练习反馈摘要，点击后进入独立二级页。
2. 反馈页默认展开练习趋势；累计统计和数据口径可以独立折叠，避免个人页被长图表占满。
3. “账号与同步”页保持本地模式兜底；Supabase 构建配置存在时开放邮箱 Magic Link，并只对服务端已配置的第三方 Provider 启用入口；迁移预览下方实时显示本机 outbox 的待同步和失败数量，录音明确标注为默认不入队。

### 调整应用设置

1. 从“我的”进入“应用设置”，选择跟随系统、浅色或深色主题，修改后立即作用于整个 App。
2. 默认练习倍速支持滑动、±0.01、精确输入和常用值；打开整曲练习时自动应用，打开已保存片段时优先采用片段自己的建议倍速。
3. 主题和默认倍速保存在 Android 本地，重新启动 App 后仍然生效；“恢复默认设置”会回到跟随系统和 1.00x。

### 录制练习与对比成果（片段试录与计划成果时间线已完成）

1. 在整曲或 A-B 片段练习页点击录音，授权麦克风并经过倒计时后开始录制自己的演奏；建议佩戴耳机，减少原曲串音。
2. 停止后可沿共享相对时间轴在原曲区间和“我的录音”之间同位置切换、拖动回听，填写标题或复盘，并决定保存或丢弃。
3. 保存后的多次试录集中显示在练习详情中，可继续播放、拖动、修改名称与复盘或删除。
4. 从计划进入练习时，可将满意录音保存为本次计划成果。
5. 在计划的成果时间线中选择较早和较新的两条录音并排展示，通过共享相对时间轴在同一位置切换或顺序回听，先由用户主观判断进步。
6. 普通试录菜单和计划成果卡片提供“音频分析（实验）”：在设备本地展示录音波形、响度、静音占比和起音间隔线索，并明确提示它不是演奏评分、尚未与原曲对齐。

从空计划编辑器点击“新建练习”时，新建流程会携带返回意图；选择“保存到练习库”后会回到计划编辑器并自动选中新内容，不需要在一级导航之间来回查找。

## 路由原则

- 已持久化的数据使用 `sourceId` 和 `segmentId` 路由，不把完整对象放在 `extra` 中。
- 外部 Android 分享的临时解析对象可使用 `extra` 进入确认页；确认保存后立即切换为 ID 路由。
- 播放器是沉浸式全屏流程，不显示底部导航；从详情进入时，详情保留在播放器下方作为稳定返回点。
- 从计划进入播放器时携带并校验 `planId`；只有计划与当前来源匹配，且目标片段仍存在时，自动记录才关联该计划。
- 内容详情属于练习库分支，始终保留底部导航和练习库返回关系。
- 四个一级分支使用独立导航栈，切换 Tab 后保留各自位置。

## 逐步开发顺序

1. **导航与新建闭环**：四个稳定一级分支、全局新建、内容详情、ID 路由。
2. **本地视频**（已完成 Android 首版）：系统相册/文件选择、文件持久化、本地播放器和统一控制器。
3. **练习库、片段与笔记**（已完成首版）：平台/完成/计划状态组合筛选与手动完成标记、公开来源标题/封面及来源信息、曲目总体笔记、片段编辑、毫秒精度 A/B 时间、默认倍速、片段局部笔记、进度条区间标记、A 点点击切换和 Markdown 笔记导出均已接入。
4. **练习计划**（已完成首版）：计划数据模型、曲目/片段选择、次数/时长目标、日期、新建/编辑/删除、今日状态、本周总览和 Android 练习提醒已接入。
5. **练习记录与反馈**（已完成首版）：Session 数据模型、本地视频/B站播放器自动记录、后台恢复检查点、“补记本次”、今日/本周汇总、14 天/12 周时长趋势、累计统计和连续练习已接入。
6. **个人中心**（进行中）：训练反馈二级页、本地数据状态、Supabase Auth 客户端、本机同步 outbox 状态、账号与同步规划、主题模式和默认练习倍速已接入；下一步是完成邮箱真机闭环、Google Provider、Supabase 元数据上传/拉取、本地数据管理、支持和问题反馈。
7. **练习录音与成果对比**（R4 进行中）：Android 录音、片段人工同位置回听、来源详情录音管理，以及计划成果时间线、双录音同位置切换和顺序回听已完成；用户录音的本地波形、响度和实验性起音间隔分析已接入，下一步是本地原曲参考节奏对齐。

BPM、按节拍循环和虚拟陪伴形象继续保留在产品范围内，但它们依赖节拍数据或产品验证，不阻塞以上主链路。
