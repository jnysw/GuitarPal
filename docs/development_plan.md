# GuitarPal 开发计划

更新日期：2026-10-28

本计划以“功能模块-2”思维导图为产品范围基线。开发顺序按完整用户闭环排列，而不是按页面数量排列：先让用户能导入、练习、保存片段和复用，再补计划跟进、统计和个人中心。

2026-10-27 新增 AI 音频主线：按 [扒和弦与分轨规划](ai_audio/development_plan.md) 开发，[阶段进度](ai_audio/progress.md) 跟踪 GP-AI-001–014。本轮完成仓库审计与第一批时间轴/结果/模型登记契约；真实权重复现、上传与持久任务、模型闭环尚未完成。既有账号和 outbox 保留，元数据跨设备同步按新规划放到后续 P2。

Windows API 客户端第四批：在真实和弦/分轨、Drift v11 任务缓存及逐轨下载基础上，新增分轨练习页面：单输出混音、音量/静音/独奏、共享进度、0.01 倍速、A-B 及本机设置恢复。六轨模式和人声＋伴奏模式均已通过 Windows 真实输出联调。和弦裁剪时间轴、视频同步、统一练习统计仍待后续接入。实现边界见 [分轨练习说明](ai_audio/stem_mix_practice.md)。

## 产品主流程

1. 从分享链接或本地文件创建练习来源。
2. 在练习模块中播放、调速、设置循环和记录笔记。
3. 把有价值的区间保存为片段并在练习库复用。
4. 将曲目或片段加入计划，记录每次练习。
5. 在训练跟进中查看今日、周和总进度。

### 阶段验收

- 分享一个受支持链接后，可以保存、播放、控制进度、设置循环并在下次启动时复用片段。
- 从 Android 相册或文件选择视频后，可以确认名称、保存副本、在 App 内练习并复用片段。
- 播放失败不会破坏已保存内容，用户仍可打开原来源。

## 阶段 2：练习计划与记录（完成）

- [x] 新建计划：开始/截止日期、重复星期、曲目或片段、目标循环次数/时长。
- [x] 我的计划：修改、删除，以及当天待完成/已完成状态。
- [x] 从练习库的整曲或已保存片段预填新计划。
- [x] “补记本次”可手动补录练习时长或循环次数，并累计更新今日计划进度，作为播放器记录遗漏或引用型来源外部练习的兜底。
- [x] 今日页展示当天计划完成比例、练习时长、记录次数和循环次数。
- [x] 从计划进入本地视频或 B站播放器时关联计划与目标片段；正常离开练习页后，按实际播放时长、A-B 循环次数、来源、片段和完成状态自动生成练习记录。
- [x] 自动统计只累计实际播放时间，暂停及应用进入后台的时间不计入；不足 1 秒且没有完成循环的空会话不落盘。
- [x] 引用型来源在计划页显示“打开原内容”，通过系统可用应用访问原链接，并保留“补记本次”记录外部练习。
- [x] 本周进度和总览：按周一至周日展示每日状态，并汇总计划完成项、有效练习时长、记录次数和循环次数。
- [x] 空计划编辑器可直接去新建练习；保存后返回计划编辑器并自动选中新内容，练习库空状态也提供明确的新建入口。
- [x] 提醒时间与重复日期：计划可启停并选择本地时间；Android 使用非精确省电闹钟，在计划重复日提醒，并在开机、应用更新、系统时间或时区变化后重排。
- [x] 提醒快捷管理：计划页提供提醒中心，每张计划卡可直接开启、关闭或改时间，个人中心也有统一入口，不必进入计划编辑器。
- [x] 为异常进程终止等未触发播放器正常退出的场景增加练习记录检查点：播放器进入后台时以稳定记录 ID 写入未完成快照，正常退出后由最终记录覆盖；有效快照同样计入今日与本周统计。

阶段验收已完成：一个整曲或已保存片段可加入计划；从计划进入本地视频或 B站播放器练习后，记录会自动关联到对应计划并更新今日进度；引用型来源可打开原内容并通过“补记本次”更新进度；重启 App 后计划、提醒和已写入记录仍保留。播放器后台检查点为异常终止提供最近一次有效练习快照。

## 阶段 3：练习库增强（完成）

- [x] 按平台、完成状态和计划状态筛选：支持条件组合、快速移除条件；完成状态由用户显式标记，计划状态根据已有计划实时推导。
- [x] 曲目来源信息和封面增强：导入时从公开 Open Graph 元数据补全标题与 HTTPS 封面，失败时回退平台图标和默认标题；练习库、确认页与详情页展示封面，详情可查看/复制来源链接并手动刷新已有内容。
- [x] 曲目下集中管理片段与笔记：详情页集中展示曲目总体笔记与 A-B 片段；总体笔记支持添加、编辑和清空，片段保留各自局部笔记，练习库可按笔记内容搜索并显示笔记标记。
- [x] 笔记导出：将曲目总体笔记及有笔记的 A-B 片段整理为 Markdown，保留来源、毫秒精度区间和 0.01 精度建议倍速；Android 支持系统分享，并提供复制全文兜底。

## 阶段 4：训练反馈与个人中心

- [x] 最近两周和长期练习时长趋势：支持最近 14 天与近 12 周切换，空日期保留在时间轴中，历史练习会自动刷新图表。
- [x] 已完成曲目/练习统计：汇总累计有效时长、练习次数、A-B 循环、活跃天数、当前连续天数及已完成曲目。
- [x] 反馈信息架构：个人中心展示摘要，完整趋势、累计统计和数据口径在独立二级页中按模块折叠。
- [x] 应用设置：支持跟随系统、浅色和深色主题；默认练习倍速可在 0.50x–2.00x 范围内以 0.01x 精度滑动、微调或直接输入，并在 Android 本地持久化。片段自己的建议倍速继续优先于应用默认值。
- [x] 账号与同步前置设计：保留无需登录的本地模式，新增账号说明页，并明确认证、本地数据合并、增量同步、冲突处理和录音隐私的分阶段方案。
- [x] 账号客户端基础：页面从供应商无关的账号会话仓库读取状态；本机曲目、片段、计划、练习记录、录音和笔记形成实时迁移预览，真实认证接入后无需改写页面或现有业务流。
- [x] 认证协议基础：按已配置能力启用邮箱、Google 或 Apple 入口；实现 OAuth/OIDC PKCE S256 请求、一次性 `state`/`nonce`、回调地址与状态校验，以及供应商身份到应用账号会话的转换。系统浏览器回调、令牌交换与安全存储留待认证服务确定后接通。
- [x] Supabase Auth 客户端：接入邮箱 Magic Link、Google OAuth 调用、Android 登录 Deep Link、PKCE 会话恢复、平台安全存储、认证状态监听与退出登录；没有 Supabase 构建配置或初始化失败时继续使用本地模式。
- [x] Supabase 回调允许列表：已在 Authentication → URL Configuration 中保存 `com.guitarpal.app://login-callback/`，并确认列表中仅有该条 GuitarPal 登录回调。
- [x] 本机同步 outbox：曲目、片段、计划和练习记录的保存、编辑、删除与级联引用变化会在同一事务中合并入队；数据库升级会补入旧元数据，修订号可防止上传中的旧请求误确认较新的本机修改，账号页展示待同步和失败数量。录音默认不入队。
- [ ] Supabase 认证闭环：完成真机邮箱 Magic Link 回跳验证；随后配置 Google Web OAuth Client 与 Supabase Google Provider，再启用 Google 构建开关。

- [ ] 个人资料和头像。

## 阶段 5：练习录音与成果对比（新增需求）

- [x] Android 录音基础：麦克风权限、原生 AAC/M4A 录制、应用私有文件管理、异常中断清理，以及录音数据表和仓库；已通过模拟器真实录制、提交、路径解析和删除集成测试。
- [x] 片段练习录音：本地视频与 B站播放器均可从整曲或 A-B 片段开始录音，保存来源、计划、片段、区间与倍速快照，并在共享相对时间轴上切换原曲/我的录音回听。
- [x] 录音管理：同一来源或片段可保留多次试录；练习详情按时间倒序展示并支持播放、进度拖动、标题/复盘编辑和音频文件删除。
- [x] 计划成果录制：录音预览可明确保存为当前计划成果，已关联计划的普通试录也可转为成果；成果按时间线展示，并支持选择两个不同日期的录音、共享相对进度、同位置切换及“较早 → 较新”顺序回听。
- [ ] 音频分析探索：已接入 Android 本地 M4A 解码、波形、响度、静音占比和实验性起音间隔分析，并明确显示适用限制、不输出演奏评分；下一步对本地视频参考区间做节奏对齐，再验证单音音高轨迹及和弦、失真与复音场景。

## 暂缓项

- BPM 模式及根据 BPM 自动换算倍速：需要先定义视频原始 BPM 与节拍来源。
- 按小节/节拍设置循环、循环间隔按节拍：依赖可靠的节拍数据。
- 跨设备同步：客户端产品边界与分阶段方案已确定，进入实现前仍需完成认证/后端选型、隐私政策和服务成本评估，详见 [账号与同步方案](account_and_sync_plan.md)。

这些项目不是删除，而是在数据定义和核心闭环稳定后再进入开发，避免播放器和计划模型反复重构。
