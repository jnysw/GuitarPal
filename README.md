# GuitarPal

AI 扒和弦与分轨开发已启动：Debug 专用“我的 → 音频工具（实验）”支持选择音频/已有录音、确认上传到 Windows 算法 API、恢复任务和缓存结果。七轨结果可逐轨下载、离线试听，并进入分轨练习，使用共享进度、音量/静音/独奏、0.01 倍速、A-B 循环和本机设置恢复。已通过 Tailscale 与 Android 模拟器真实六轨/双轨播放联调。旧和弦 v1 裁剪偏移未知，和弦原曲同步及视频播放器联动仍待开发。操作见 [客户端联调说明](docs/ai_audio/windows_client_setup.md)，范围见 [AI 音频规划](docs/ai_audio/development_plan.md)，每批实现、验证和依赖见 [阶段进度](docs/ai_audio/progress.md)。

把值得学习的视频内容整理成可重复、可跟踪的吉他练习。

当前可用链路：从 Android 分享 B站链接，或从相册/文件导入本地视频；保存到练习库后可在 App 内播放，并使用进度、精确倍速、媒体音量、A-B 循环与已保存练习片段。分享链接导入会尽力从公开 Open Graph 信息补全页面标题与 HTTPS 封面，失败时仍使用平台默认标题和图标正常保存；练习详情可查看、复制来源链接，也可手动刷新已有来源的标题与封面。每个来源支持一份曲目总体笔记，每个 A-B 片段可保存自己的局部笔记；练习详情集中管理两层内容，练习库也能按笔记文字搜索并显示笔记标记。曲目和片段笔记可连同片段区间、建议倍速导出为 Markdown，通过 Android 系统分享或直接复制。练习库还可组合按来源平台、待练/已完成及有计划/无计划筛选；完成状态可在列表或详情页手动切换。倍速在 0.50x–2.00x 范围内支持 0.01x 滑动/按键微调、数字输入和常用值快选；音量在 0–100% 范围内以 1% 步进调节，并可静音/恢复。本地 Android 播放器通过 `TextureView` 正确合成视频画面，本地视频和 B站练习页的全屏模式都保留进度、音量与基础播放控制，播放时控制层会自动隐藏，点击画面可唤起，系统返回键会先退出全屏。片段可编辑名称、毫秒精度 A/B 时间、默认倍速和练习笔记；进度条会显示已保存区间，点击 A 点即可切换片段，重新打开时会恢复循环区间与倍速。

练习计划也已进入可用链路：可以为整曲或片段设置起止日期、重复星期、练习提醒，以及循环次数或练习时长目标；计划支持编辑和删除。提醒既可从计划卡片直接调整，也可在计划页或个人中心进入提醒中心集中管理。Android 会按设备本地时间安排提醒，并在开机、应用更新或时区变化后重新同步。从计划进入本地视频或 B站播放器后，会按实际播放时长和 A-B 循环次数自动生成练习记录，并累计到“今日”完成比例与时长摘要；进入后台时还会写入恢复检查点，降低异常进程终止导致记录丢失的风险。计划页会汇总周一至周日的完成项、练习时长、记录数和循环数。引用型来源会直接“打开原内容”，无法自动统计或播放器记录遗漏时可使用“补记本次”兜底。从空计划页新建练习时，保存后会自动回到计划编辑器并选中新内容。“我的”页面以摘要进入独立练习反馈页，可折叠查看最近 14 天/近 12 周趋势、累计时长、有效练习、A-B 循环、练习天数、连续练习和已完成曲目；应用设置支持跟随系统、浅色和深色主题，以及 0.01x 精度的默认练习倍速。账号页继续保持无需登录的本地模式，同时已接入 Supabase Auth：支持邮箱 Magic Link、Google OAuth 调用、Android Deep Link、PKCE 会话恢复和平台安全存储，登录入口会按实际 Provider 配置启用；本机曲目、片段、计划、练习记录、录音和笔记会形成迁移预览。曲目、片段、计划和练习记录的本机变更现已事务化写入同步 outbox，旧数据升级时会自动补入，账号页可查看待同步数量；录音仍默认不入队。Google Provider、服务端表和实际上传/拉取仍在后续阶段。

Android 练习录音也已进入可用链路：本地视频和 B站练习页可在 3 秒倒计时后录制用户演奏，保存当前来源、计划、A-B 区间、关联片段和倍速快照。停止后可沿共享相对时间轴在“原曲”和“我的录音”之间同位置切换、播放、暂停与拖动，填写名称和练习复盘后保存。练习详情会按时间倒序集中显示多次试录，支持独立播放、进度拖动、编辑名称/复盘、转为计划成果和删除。计划录音可在预览时明确保存为成果，并从计划卡片进入成果时间线；选择较早和较新的两条成果后，可使用共享相对进度在同一位置切换，或按时间顺序连续回听。普通试录和计划成果还可在 Android 设备本地执行实验性音频分析，展示波形、响度、静音占比和起音间隔线索；界面明确标注它不是演奏评分，当前也尚未与原曲音轨对齐。音频使用 AAC/M4A 保存在应用私有目录，删除记录时同步清理文件。

## 本地运行

```bash
flutter pub get
flutter run
```

启用本机 Supabase 邮箱登录构建：

```bash
flutter run --dart-define-from-file=config/supabase.local.json
```

本地配置文件不会进入 Git；首次配置、Android 回调地址和 Google Provider 步骤见 [Supabase 配置](docs/supabase_setup.md)。

静态检查与测试：

```bash
flutter analyze
flutter test
```

## 项目结构

- `lib/domain`：不依赖界面的业务对象和仓库接口。
- `lib/features`：首页、分享导入、练习库、播放器、片段管理和练习计划。
- `lib/media`：来源适配器、网页/本地播放器桥接和循环控制。
- `lib/core`：数据库、URL 处理、系统分享和本地文件接入。

完整功能范围、优先级和验收标准见 [开发计划](docs/development_plan.md)。

新增的练习录音、片段人工对比、计划成果时间线及后续音频分析方案见 [练习录音与成果对比规划](docs/practice_recording_plan.md)。

账号、首次登录迁移、离线同步、冲突处理和录音隐私方案见 [账号与同步方案](docs/account_and_sync_plan.md)。
